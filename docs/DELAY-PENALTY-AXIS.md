## 1. 왜 이 축을 먼저 여는가

| 후보 축 | 결정론 가능성 | 판단 여지 | 판정 |
|---|---|---|---|
| **지체상금** | 요율·기준금액·한도가 전부 법정 산식 | 지체일수 산정(사실 판단)만 | **1순위** |
| 물가변동 조정 | 지수·품목조정률 계산은 결정론 | 조정요건·기준일·특약 다툼 큼 | 2순위 |
| 설계변경 | 단가 산정 원칙만 규범 | 신규비목 단가 협의가 본질 | 후순위 |
| 부정당 제재 | 별표 기준은 결정론 | 처분 재량·감경이 본질 | 후순위(검색으로 충분) |

지체상금은 **입력 4개(계약금액·유형·기관유형·지체일수)로 금액이 확정**된다. 실무자가 손으로
계산하다 틀리는 지점(국가/지방 요율 차이, 기성 인수분 공제, 30% 한도)이 정확히 도구가 이기는
지점이고, 우리 회귀 하네스로 못박을 수 있다.

## 2. 실측 근거 (2026-08-14 라이브 코퍼스 조회 — 기억으로 적지 않았다)

| | 국가·공기업 | 지방자치단체 |
|---|---|---|
| 법정 용어 | **지체상금** | **지연배상금** |
| 근거 | 국가계약법 제26조 · 영 제74조 · 규칙 제75조 | 지방계약법 제30조 · 영 제90조 · 규칙 제75조 |
| 공사 | 1천분의 **0.5** | 1000분의 **0.5** |
| 물품 제조·구매 | 1천분의 **0.75** (설계·제조 일괄+승인물품 0.5) | 1000분의 **0.8** (같은 예외 0.5) |
| 물품 수리·가공·대여, 용역, 기타 | 1천분의 **1.25** | 1000분의 **1.3** |
| 군용 음·식료품 | 1천분의 1.5(제4호) | **해당 호 없음**(전문 401자 전수 확인 — 4개 호뿐). 제4호는 국가 규칙이 제2호에서 떼어낸 특칙이므로 그 특칙이 없는 지방에선 **제2호 '물품의 제조·구매' 0.8**로 남는다고 해석 — **법문이 아니라 우리 해석이라 `rate.inferred`로 실토한다** |
| 운송·보관·양곡가공 | 1천분의 2.5 | 1000분의 2.5 |
| 기준금액 | 계약금액(장기계속=**연차별** 금액) | 동일 |
| 기성·기납 인수분 | 그 금액을 **공제한 금액** 기준(영 제74조②) | 동일(영 제90조②) |
| 한도 | 계약금액의 **100분의 30**(영 제74조③, 신설 2018.12.4) | 동일(영 제90조③, 신설 2019.6.25) |
| 면책 | 계약상대자 책임 없는 사유 일수는 **지체일수 미산입**(①) | 동일(①) |
| 공동계약 특칙 | 영 제74조는 ①②③뿐 — **해당 항 없음**(전문 확인). 예규(공동계약운용요령) 별도 확인 대상 | 분담이행 시 **지연을 직접 야기한 구성원**에게 부과(영 제90조④, 신설 2016.11.29) |

> **국가와 지방의 요율이 다르다**(물품 0.75↔0.8, 용역 1.25↔1.3). 이 저장소에서 이미 두 번
> 재발한 결함 계열(R15·R16 — 지방 판정에 국가 수치 혼입)이 이 축에서 그대로 되풀이될 수 있다.

## 3. 도구 계약 (신규 도구 `estimate_delay_penalty`, readOnlyHint)

`decide_contract_method`에 얹지 않는다 — 그쪽은 '발주 전 계약방법'이 계약이라 입력·출력의 의미가
다르고, 한 도구에 두 축을 섞으면 설명이 모호해져 클라이언트가 잘못 고른다(탐침이 반복 지적한 계열).

**입력(flat)**
- `contract_kind`: `construction|product_manufacture|product_repair|service|military_food|transport_storage`
  — 요율 호(號)와 1:1. 자유문자열 금지, `Literal`로 스키마에 허용값을 싣는다.
- `org_type`: `national|local|public_corp` — **필수. 미지정 시 추측하지 않고 거부**(요율이 다르다).
- `contract_amount`: 계약금액(원). 장기계속이면 **연차별** 금액을 넣도록 설명문에 명시.
- `delay_days`: 지체일수(사용자 선언값).
- `excluded_days`(기본 0): 계약상대자 책임 없는 사유 일수(사용자 선언값).
- `accepted_portion_amount`(기본 0): 검사·인수된 기성·기납 부분 금액.
- `design_build_approved`(기본 false): 설계·제조 일괄+발주기관 승인 물품(요율 0.5 예외).

**출력**
```
term            "지체상금" | "지연배상금"          # 기관유형에 따라 법정 용어가 다르다
rate            {"value": 0.0005, "as_text": "1천분의 0.5", "basis": "국가계약법 시행규칙 제75조 제1호"}
base_amount     {"contract_amount":…, "accepted_deducted":…, "result":…}   # 산출 내역을 편다
counted_days    {"declared": 40, "excluded": 10, "result": 30}
amount_raw      base_amount.result × rate × counted_days.result
cap             {"limit_rate": 0.3, "limit_amount":…, "applied": true|false}
amount          min(amount_raw, cap.limit_amount)
legal_basis[]   조문 키 목록 (get_law_article로 원문 확인 가능)
warnings[]      아래 §4의 실토 항목
uncertainties[] 기관 자체 계약규정·계약서 특약 우선 가능성 등
```

## 4. 인식 경계 계약 — 이 축에서 도구가 거짓말할 수 있는 자리

1. **지체일수를 우리가 아는 척하지 않는다.** 준공검사 소요기간·검사 불합격 재검사 기간·부분
   납품의 납기 분리는 **사실 판단**이라 도구가 못 한다. 입력값은 '선언값'으로 표시하고
   (`counted_days.declared`), 면책 사유 판단은 `search_references`(예규·감사원 실무가이드)로
   넘기는 안내를 응답에 싣는다. **계산해 주되 확정해 주지 않는다.**
2. **기관유형 미지정에 기본값을 쓰지 않는다.** 요율이 다르므로 `org_type` 없는 호출은 계산
   자체를 거부하고 무엇이 필요한지 알린다(조용한 국가 폴백 = 지자체 사용자에게 틀린 금액).
3. **30% 한도를 조용히 적용하지 않는다.** `cap.applied=true`와 `amount_raw`를 함께 낸다 —
   한도로 깎였다는 사실이 실무자에게 가장 중요한 정보다.
4. **인수분 미선언은 0이 아니라 경고다.** `accepted_portion_amount`가 없으면 계산은 전액
   기준으로 하되 "기성·기납 인수분이 있으면 공제 후 재계산해야 한다"를 warnings에 싣는다.
5. **용어 비대칭을 실토한다.** 지방 응답에서 '지체상금'이라 쓰면 사용자가 계약서에서 그 말을
   못 찾는다. `term`을 기관유형에서 파생하고, 반대 용어를 병기한다.
6. **요율표 신선도.** 응답에 `rate_article_amended`(근거 조문 개정일)와 `rules_updated`(우리 룰
   파일 갱신일)를 함께 낸다. 원천 감시는 이미 법령 단위로 돌고 있다 — `tools/check_law_freshness.py`의
   매니페스트에 국가·지방 시행규칙이 모두 있어 개정 시 STALE로 걸린다(별도 등록 불필요, 실측 확인).
   걸린 뒤 `rules/delay_penalty_rules.json` 갱신은 사람 몫이다.
7. **계약서 특약 우선.** 예규(공사계약일반조건 제25조·용역계약일반조건 제18조)와 기관 자체
   규정이 세부를 달리 정할 수 있다 — uncertainties 상시 노출.

## 5. 구현 배치

- `rules/delay_penalty_rules.json` **(신규)** — 요율표·한도·근거조문·개정일. **코드에 숫자를 박지
  않는다**(CLAUDE.md 규칙 — 판정 수치의 진실원은 rules/).
- `backend/services/delay_penalty.py` — 순수 계산 함수(외부 의존 0). 정적 SEO 페이지 생성기도
  같은 함수를 쓰게 해 사본이 갈리지 않게 한다(rule_engine.rule_method와 같은 이유).
- `backend/api/v1/penalty.py` **(신규 라우터)** — `POST /api/v1/penalty/delay`. 구조화 실패(400 +
  error/message/hint)로 거부를 돌려준다.
- `mcp/server.py` — 도구 노출 + `SERVER_VERSION` 마이너 범프(도구 추가는 계약 변경).

## 7. 단계

- **Phase 1** — 위 도구 1종(요율·기준금액·한도·실토). 질문은행 이행-053~060이 그대로 평가 문항.
- **Phase 2**(완료) — 면책 사유 **갈림길 지도**: 사유 9종(불가항력·관급자재 지연·발주기관 귀책·
  보증이행·설계변경·혁신제품 하자·원자재 수급·용역 SW 절반규칙·물품 승인지연)을 예규 원문
  인용과 함께 펴고, 사유마다 **확정돼야 할 사실**을 질문으로 준다. 일수·금액 규칙 4종
  (준공검사 기간 불산입·최종 확정 계약금액 기준·분할납품 대상액·장기계속 차수별)과 기재부·
  행안부 회신 선례 4건 포함. **판정은 하지 않는다** — 일반조건이 발주기관의 인정을 요건으로
  두기 때문이고, 그 사실을 응답마다 싣는다. 회수 인용이 끊긴 2건은 `quote_truncated`로
  실토하고 전문 확인 경로를 준다(끊긴 문장을 이어 붙이지 않는다).
- **Phase 3**(완료) — 물가변동 계약금액 조정. **결정론인 부분만** 도구화했다: 90일 기간 요건
  (계약체결일 또는 직전 조정기준일 기산, 경계 포함)·3% 등락률 문턱·단품 조정 문턱
  (**국가 15% / 지방 10%** — 2024 개정으로 갈렸다)·방식 결정 규칙(계약서에 지수조정률
  명시가 없으면 품목조정률)·조정금액과 선금 공제 산식(시행규칙 제74조 제5·6항).
  **조정률 자체는 산정하지 않는다** — 지수·단가 원천을 우리가 갖고 있지 않으므로, 값이
  없으면 `undetermined`로 판정을 보류하고 원천(한국은행 생산자물가지수 등)을 안내한다.
  90일 예외(천재지변·원자재 급등)는 발주기관 인정 사항임을 함께 낸다.
